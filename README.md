# YeastInArcticConditions
Data and code associted with the article "Yeast can substitute conventional CO2 producers for monitoring species richness of biting flies in arctic conditions" by V. Gårdman and P. Gårdman (unpublished)

Viktor_c_flux contain raw .txt files on CO2 emission rates in ppm per day and hour of measurement. CO2_releaserate_cleaning.R is an R script for turning these raw files into ml CO2 released per minute, saved as CO2_per_minute.csv. CO2_analysis.R contains the script for running all analysis from the article, using the data in CO2_per_minute.csv, Attractant_data.csv, and Yeast_canister_data.csv.

CO2_per_minute.csv contain the release rate of ml CO2 per minute (mlpermin) per date (EVENT DATE), hour of measurement (Hour), and replica (SourceFile). Note that due to conversion issues of date formats between the EGM-5 to .txt files, the dates in 'EVENT DATE' do not correspond to the actual dates--they are adjusted to the proper dates in the CO2_cleanscript.R file. The release rate in ml per minute was obtained by first calculating total release in ppm (TotalRelease) divided by the fraction of a minute that the total release was measured for (TimeSec / 60), and then converting ppm to ml by accounting for temperature (Temp) and pressure (Pressure). See CO2_releaseratecleaning.csv for more details on the conversion.

Attractant_data.csv contain data on the capture rates of mosquitoes and blackflies with BG-pro traps equiped with yeast-based CO2 production, lures, both OC2 and lures, and without any attractant. The file gives the number of individuals (Count) captured per day (See Date for YYYYMMDD, Date_Num for numeric date) and combination of attractants (TrapType), along with the number of hours of sampling (Hours_sampling). Hours sampling is the time between start of sampling (Time_Start) and end of sampling (Time_End). The individual count per traptype and date is given per species (Species). Also provided is the taxonomic family (Family). See column Comment for extra information on individual sampling bouts.
 
Yeast_canister_data.csv contain data on the comparison of trap catches of mosquitoes and blackflies between BG-pro traps utilizing yeast and CO2 canisters as CO2 sources. The file provides species-specific (Species) and taxonomic family (Family) captures (Count) per day of sampling (Date, given as YYYYMMDD), attractant type (TrapType), trap area (Site), time of sampling (Time_Start:Time_End) and hours of sampling (Hours_sampling). Capture rate (CountPerHour) is given as the total captures divided by the hours of sampling.
